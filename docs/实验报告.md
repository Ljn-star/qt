### 3.1 UI 布局与设计

主窗口用 Qt Designer 完成：`QMainWindow` 中央放置一个 `QVBoxLayout`，布局的
`leftMargin/topMargin/rightMargin/bottomMargin` 全部设为 **0**，里面只放一个
编辑控件 `textEdit`。这样文本区可以占满窗口，不会出现默认的 9px 边距。

菜单与工具栏通过 **Action 编辑器** 创建，按功能分组：

- 文件：新建、打开、保存、另存为、退出；
- 编辑：撤销、恢复、剪切、复制、粘贴、查找、替换、全选；
- 格式：自动换行、显示行号、字体、字体颜色、字体背景色、编辑器背景色；
- 查看：工具栏、状态栏；
- 帮助：关于。

关键代码（`mainwindow.ui`，节选）：

```xml
<widget class="QWidget" name="centralWidget">
 <layout class="QVBoxLayout" name="verticalLayout">
  <property name="spacing"><number>0</number></property>
  <property name="leftMargin"><number>0</number></property>
  <property name="topMargin"><number>0</number></property>
  <property name="rightMargin"><number>0</number></property>
  <property name="bottomMargin"><number>0</number></property>
  <item>
   <widget class="CodeEditor" name="textEdit"/>
  </item>
 </layout>
</widget>
```

编辑区使用从 `QPlainTextEdit` 派生的 `CodeEditor`，在 Designer 里通过
**"提升为"（promote）** 使用：

```xml

  <header>codeeditor.h</header>
 </customwidget>
</customwidgets>
```

### 3.4 替换对话框

替换对话框在查找对话框基础上增加"替换为""替换""全部替换"。
全部替换用 `QTextDocument::find()` 循环完成，并用 `beginEditBlock()` 把整个
替换过程合并成一次可撤销的操作：

```cpp
QTextCursor cursor(m_editor->document());
if (flags & QTextDocument::FindBackward)
    cursor.movePosition(QTextCursor::End);
cursor.beginEditBlock();

int count = 0;
QTextCursor found = m_editor->document()->find(target, cursor, flags);
while (!found.isNull()) {
    found.insertText(replacement);
    ++count;
    found = m_editor->document()->find(target, found, flags);
}
cursor.endEditBlock();
```

### 3.5 新建/打开/保存/另存为

文件操作统一走 `loadFile()` / `saveFile()`：

- 新建：若有未保存修改先 `maybeSave()`，然后清空并重置标题；
- 打开：文件不存在、无法读取、包含二进制数据（`\0`）、超过 20MB 时给出提示并
  保持原内容不变；
- 保存：未命名时转去"另存为"，否则直接写回当前文件；
- 另存为：用户未写扩展名时自动补 `.txt`；
- 关闭窗口：`closeEvent()` 调用 `maybeSave()`，提供保存/不保存/取消三种选择。

```cpp
bool MainWindow::maybeSave()
{
    if (!ui->textEdit->document()->isModified())
        return true;
    const auto ret = QMessageBox::warning(this, tr("提示"), tr("文档已修改，是否保存？"),
                                          QMessageBox::Save | QMessageBox::Discard
                                          | QMessageBox::Cancel);
    if (ret == QMessageBox::Save) {
        if (m_currentFile.isEmpty()) {
            on_actionSaveAs_triggered();
            return !ui->textEdit->document()->isModified();
        }
        return saveFile(m_currentFile);
    }
    return ret != QMessageBox::Cancel;
}
```

窗口标题使用 `[*]` 占位符，未保存时自动显示 `*`：

```cpp
setWindowTitle(tr("%1[*] - 编辑器").arg(name));
```

### 3.9 查找与替换功能

查找/替换逻辑分别在 `FindDialog` 与 `ReplaceDialog` 中实现，两个对话框都
持有编辑器的指针，直接对 `QPlainTextEdit` 做查找与替换。

**(1) 查找：连续查找 + 未找到提示**

```cpp
void FindDialog::on_btnFind_clicked()
{
    const QString target = ui->lineEditTarget->text();
    if (target.isEmpty()) {
        QMessageBox::information(this, tr("查找"), tr("请输入要查找的内容。"));
        return;
    }

    QTextDocument::FindFlags flags;
    if (ui->checkCase->isChecked())
        flags |= QTextDocument::FindCaseSensitively;
    const bool backward = ui->radioUp->isChecked();
    if (backward)
        flags |= QTextDocument::FindBackward;

    if (!m_editor->find(target, flags)) {
        // 找不到时从文档首/尾回绕再找一次，实现"连续查找"
        QTextCursor cursor = m_editor->textCursor();
        cursor.movePosition(backward ? QTextCursor::End : QTextCursor::Start);
        m_editor->setTextCursor(cursor);
        if (!m_editor->find(target, flags)) {
            QMessageBox::information(this, tr("查找"), tr("未找到“%1”。").arg(target));
            return;
        }
    }
    m_editor->setFocus();
}
```

`QPlainTextEdit::find()` 从当前光标位置开始查找；第一次找不到时把光标移到
文首（向下查找）或文末（向上查找）再找一次，实现回绕；两次都找不到才提示
"未找到"。因此连续按"查找下一个"可以从头循环查找。

**(2) 替换：查找下一个 / 单次替换 / 全部替换**

```cpp
bool ReplaceDialog::findNext()
{
    const QString target = ui->lineEditTarget->text();
    if (target.isEmpty()) {
        QMessageBox::information(this, tr("替换"), tr("请输入要查找的内容。"));
        return false;
    }

    const QTextDocument::FindFlags flags = findFlags();
    if (m_editor->find(target, flags))
        return true;

    // 回绕再找一次
    QTextCursor cursor = m_editor->textCursor();
    cursor.movePosition(ui->radioUp->isChecked() ? QTextCursor::End : QTextCursor::Start);
    m_editor->setTextCursor(cursor);
    if (m_editor->find(target, flags))
        return true;

    QMessageBox::information(this, tr("替换"), tr("未找到“%1”。").arg(target));
    return false;
}

void ReplaceDialog::on_btnReplace_clicked()
{
    const QString target = ui->lineEditTarget->text();
    if (target.isEmpty()) {
        QMessageBox::information(this, tr("替换"), tr("请输入要查找的内容。"));
        return;
    }

    if (selectionMatches(target)) {
        QTextCursor cursor = m_editor->textCursor();
        cursor.insertText(ui->lineEditReplace->text());
        m_editor->setTextCursor(cursor);
    }
    findNext();   // 替换后自动查找下一个
}

void ReplaceDialog::on_btnReplaceAll_clicked()
{
    const QString target = ui->lineEditTarget->text();
    if (target.isEmpty()) {
        QMessageBox::information(this, tr("替换"), tr("请输入要查找的内容。"));
        return;
    }

    const QString replacement = ui->lineEditReplace->text();
    const QTextDocument::FindFlags flags = findFlags();

    QTextCursor cursor(m_editor->document());
    if (flags & QTextDocument::FindBackward)
        cursor.movePosition(QTextCursor::End);
    cursor.beginEditBlock(); // 让"全部替换"成为一次可撤销的操作

    int count = 0;
    QTextCursor found = m_editor->document()->find(target, cursor, flags);
    while (!found.isNull()) {
        found.insertText(replacement);
        ++count;
        // insertText 后游标位于替换文本之后，从这里继续查找可避免死循环
        found = m_editor->document()->find(target, found, flags);
    }
    cursor.endEditBlock();

    if (count > 0)
        QMessageBox::information(this, tr("替换"), tr("共替换 %1 处。").arg(count));
    else
        QMessageBox::information(this, tr("替换"), tr("未找到“%1”。").arg(target));
}
```

说明：

- 单次替换先判断当前选区是否正好等于查找内容（是否区分大小写可配置），
  是才替换，然后自动查找下一个；
- 全部替换用 `QTextDocument::find()` 循环完成；`insertText()` 之后游标位于
  替换文本之后，从该位置继续查找可以避免"替换文本包含查找文本"时的死循环；
- `beginEditBlock()` / `endEditBlock()` 把整个全部替换合并为一次可撤销操作；
- 替换完成后统计并提示"共替换 N 处"，一处都没有时提示"未找到"。

主窗口通过两个 Action 打开对话框（非模态，可边看编辑区边操作）：

### 3.11 cut / copy / paste 按钮的使能处理

菜单项和工具栏按钮共用同一个 `QAction`，因此只要调用 `QAction::setEnabled()`，
菜单和工具栏上的按钮会同时变灰或变亮。

**主要代码（`mainwindow.cpp`）**

```cpp
// 初始状态：还没有可撤销/可复制的内容
ui->actionUndo->setEnabled(false);
ui->actionRedo->setEnabled(false);
ui->actionCut->setEnabled(false);
ui->actionCopy->setEnabled(false);

// 选区变化：copyAvailable(true) 表示当前有选中文本
connect(ui->textEdit, &QPlainTextEdit::copyAvailable,
        ui->actionCopy, &QAction::setEnabled);
connect(ui->textEdit, &QPlainTextEdit::copyAvailable,
        ui->actionCut, &QAction::setEnabled);

// 剪贴板内容变化：只有剪贴板里有文本时才允许粘贴
connect(QApplication::clipboard(), &QClipboard::dataChanged,
        this, &MainWindow::updateEditActions);

void MainWindow::updateEditActions()
{
    const bool hasClipboardText = !QApplication::clipboard()->text().isEmpty();
    ui->actionPaste->setEnabled(hasClipboardText);
}
```

**说明**

- `QPlainTextEdit::copyAvailable(bool)` 在选中文本、取消选中时都会发出，
  直接连接到 `QAction::setEnabled` 即可同步"剪切/复制"；
- 粘贴不能用 `copyAvailable`，因为剪贴板内容可能来自其它程序，
  所以监听 `QClipboard::dataChanged`，有文本才允许粘贴；
- 程序启动时先把剪切/复制置灰，避免没有选区时误点；
- 菜单和工具栏使用的是同一个 Action，状态天然保持一致。

## 七、实验总结

### 7.1 出错分析与解决

1. **保存后读回内容多出 `\r`**：Windows 下 `QIODevice::Text` 把 `\n` 写成
   `\r\n`，`setPlainText()` 读取原始字节后又保留了 `\r`。解决：加载时把
   `\r\n` 和单独的 `\r` 统一替换为 `\n`。
2. **工具栏图标不显示**：`resources.qrc` 的前缀写成 `/icons`，文件路径又是
   `icons/new.svg`，实际资源路径变成了 `:/icons/icons/new.svg`。解决：前缀改为 `/`。
3. **窗口标题多出一段应用名**：`setApplicationDisplayName()` 会被 Qt 追加到
   标题后面。解决：去掉该调用，标题只保留"文件名[*] - 编辑器"。
4. **QPlainTextEdit 没有 `textColor()`**：那是 `QTextEdit` 的接口。解决：改用
   `currentCharFormat().foreground().color()` 取初始颜色。
5. **全部替换可能死循环**：替换文本中包含查找文本时，若游标不前进会反复命中。
   解决：`insertText()` 后从替换文本之后继续查找，并用空目标保护。
